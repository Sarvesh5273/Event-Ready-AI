# EventReady AI — Final Shooting Script

**Runtime:** 2:35
**Format:** 1920×1080 landscape, H.264 MP4
**Method:** Record clean clips separately, assemble, then record voiceover last.
**Mode:** Live Mode with real photos. Demo Mode never appears on camera.
**Tone:** A finished consumer product launch. Never a hackathon entry.

---

## The three rules that decide this film

1. **EventReady is the subject of every sentence.** "EventReady measures." "EventReady proves." Never "we built," "our system," "our model," "this project."
2. **The interface is the hero.** Overlays never cover live UI. No giant animations. Show the result of the technology, not proof the technology exists.
3. **Every spoken claim has a matching visual on screen at that moment.** If you say "proves it," the proof shot is already visible.

## Non-negotiables

**Never say:** hackathon · prototype · project · we built · our system · our model · demo

**Always say:** EventReady measures · EventReady recommends · EventReady compares · EventReady proves

**Technical:**
- 1920×1080, browser zoom fixed 90–100% across every clip
- Bookmarks, notifications, extra tabs, password prompts all hidden
- No terminal, no source code, no API dashboards on camera
- Burned-in captions throughout, max two lines, checked against real UI spelling
- Cursor visible only when it communicates a choice; hidden during reveals
- Export 1080p H.264, 15–25 Mbps
- Watch once with sound, once muted, before uploading
- **Final runtime under 2:45.** Hard ceiling 3:00 — judges are not required to watch past it.

**Claims discipline:** "confidence score," "measures," "recommends," "shopping leads." Never guaranteed fit, never medical or diagnostic language, never claim the retail listings were measured.
